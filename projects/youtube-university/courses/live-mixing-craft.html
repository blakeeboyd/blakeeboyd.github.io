Before you start

Prerequisites

  • Familiar with mixing console basics (faders, EQ, compressor)
  • Some exposure to live or studio mixing

By the end you'll be able to

  • Set gain structure across an entire signal chain using send-hot turn-down-late
  • Build a subgroup-and-VCA routing scheme that produces an automix
  • Run an active soundcheck that maximizes the artist's productive time
  • Manage feedback with geometry and directivity rather than EQ
