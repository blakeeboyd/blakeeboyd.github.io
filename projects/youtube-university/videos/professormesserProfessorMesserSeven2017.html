Takeaway

Messer's premise is that subnetting on a certification exam is a math problem made worse by exam pressure. He takes all the math out of the exam by doing it once, on paper, before the clock starts. He pre-builds two reference charts. The first converts a CIDR prefix /N to a dotted-decimal mask value and lists the address-grouping size for each prefix. The second lays out the subnet-boundary addresses for each mask value (for a 64-address subnet, the boundaries are 0, 64, 128, 192). During the exam, every subnetting question collapses to a small rule set: 255 in the mask means copy the address octet, 0 means use 0 for the network address and 255 for the broadcast, any other value means look up the range in the second chart. He works four examples in increasing difficulty: /24, /26, /20, and /11. The procedure trades binary understanding for memorized scaffolding, which is the right trade when the exam clock is the binding constraint.

Before you watch

Prerequisites

  • Familiarity with an IPv4 address as four octets in decimal notation
  • Awareness that a subnet mask can be written as either /N (CIDR) or 255.x.x.x
  • Comfort with mental addition and doubling

By the end you'll be able to

  • Build the two reference charts (CIDR-to-decimal converter and address-grouping table) before the exam clock starts
  • Convert any CIDR block /1 through /32 to a dotted-decimal subnet mask using the conversion chart
  • Find the network, broadcast, first usable, and last usable addresses for any IP/mask pair
  • Apply the procedure to non-octet-aligned masks such as /20 and /26

Watch for

  • 6:21 the CIDR-to-decimal chart layout: four columns for the four octets, each column built by repeated doubling and addition
  • 8:10 the address-grouping chart for each mask value (0, 64, 128, 192 for a 64-address subnet)
  • 11:30 the rule applied: 255 means copy the address, 0 means use 0 (network) or 255 (broadcast), other values mean look up the range in the second chart

Questions

  1. 1.Messer builds two charts before any subnetting begins. Describe what each chart converts from and to, and explain why you would build them in advance rather than calculate on the fly during the exam.Understand

    The first chart maps each CIDR prefix /1 through /32 to its dotted-decimal mask value and to the size of the address grouping in the relevant octet, laid out in four columns (one per octet) so that the column where /N lands also tells you which octet of the dotted-decimal mask carries the non-trivial value. The second chart lists the subnet-boundary addresses for each common mask value (128, 192, 224, 240, 248, 252, 254), giving the starting numbers of each subnet within an octet. Building both charts before the exam clock starts shifts the time-consuming work (doubling, addition, range memorization) out of the exam and into pre-exam scratchwork, where stress is lower and arithmetic mistakes are easier to catch.

  2. 2.Apply Messer's procedure to a new problem: address 10.50.200.99 with a /22 subnet mask. Find the dotted-decimal subnet mask, network address, broadcast address, and first and last usable host addresses. Show which chart you consult at each step.Apply

    Step 1: find /22 in the first chart. /22 sits in the third column with a decimal value of 252 and an address-grouping size of 4 in that octet. So the subnet mask is 255.255.252.0. Step 2: locate 200 (the third octet of the address) in the address-grouping chart's row for groups of 4. 200 falls into the range 200-203 (since 200 is divisible by 4 and the next boundary is 204). Step 3: build the network address by copying octets where the mask is 255 (10, 50), using the start of the range where the mask is non-trivial (200), and using 0 where the mask is 0 (fourth octet). Network address: 10.50.200.0. Step 4: build the broadcast address with the same rule but the end of the range and 255 where the mask is 0. Broadcast: 10.50.203.255. Step 5: add 1 to the network and subtract 1 from the broadcast. First usable: 10.50.200.1. Last usable: 10.50.203.254.

  3. 3.Compare the /24 example to the /26, /20, and /11 examples. What changes in the procedure when the mask boundary is not aligned to an 8-bit octet, and why does the second chart become more important the further the mask drifts from /8, /16, /24, or /32?Analyze

    With /8, /16, /24, /32 the mask is either 255 or 0 in every octet, so every step resolves to "copy the address" or "use 0 or 255" with no chart lookup needed at all. The second chart becomes important the moment any octet has a mask value between 0 and 255 (192, 224, 240, 248, 252, 254), because that octet now carries the actual subnet boundaries and the address inside it has to be located in a range rather than copied or zeroed. /26 puts the non-trivial value in the fourth octet. /20 puts it in the third. /11 puts it in the second. The further the prefix is from an 8-bit boundary, the more the address has to be checked against the chart's row for that grouping size, and the more likely a student is to look up the wrong range under pressure.

  4. 4.Messer's procedure replaces binary math with table lookup. What does the engineer give up by skipping the binary conversion, and what does the procedure gain? When would you still want to fall back to binary thinking?Analyze

    The procedure gives up the conceptual link to bit-level structure: the student no longer sees that /26 means "two more network bits than /24" or that a /22 has four addresses per third-octet group because two host bits remain in the third octet. What it gains is speed and a smaller surface area for error under time pressure, since the rule set is small enough to apply almost without thinking. Falling back to binary is appropriate when the question goes beyond the four standard answers (network, broadcast, first usable, last usable). Variable-length subnet masking, supernetting, working out whether two arbitrary hosts can reach each other directly, and the edge cases of /30 point-to-point links and /31 or /32 special masks all reward binary reasoning. The seven-second method is a test-taking tool. The binary model is what it rests on.
