Takeaway

As the A1 on a corporate gig, you mix the room, run the live stream, and fire every audio playback cue from one position, so the playback rig has to be fast and hard to break. Curtis builds a corporate show in Figure 53's QLab from an empty workspace: importing audio, bundling the media into a portable project folder, patching cue outputs to the interface, and fixing a mono VOG that only plays out one channel. He then structures the cue list against a show caller's flow, separating cue numbers from cue names, color-coding cues by type, and using Auto Follow with trimmed start times to chain a keynote VO straight into a walk-on stinger. He closes with panic-duration and level trims, the small reliability decisions that keep a live playback rig dependable under pressure.

Questions

  1. 1.Curtis recommends "save workspace and media to a new project folder" rather than saving the workspace file alone. Explain what this option does and why it matters when his source audio lives in Google Drive or Dropbox and the file may move to another machine or another operator.Understand

    The option copies every imported audio file into a single project folder saved alongside the .qlab5 file, instead of referencing the originals where they sit. Curtis pulls assets from Google Drive and Dropbox, so referencing originals would break the show if a file were unsynced, offline, or opened on a different machine. Bundling also simplifies handoff: he can give another operator the whole folder with every asset inside. It plays back more reliably too, reading from a local disk rather than streaming from cloud storage.

  2. 2.Three of the VOG files are mono recordings, and by default QLab sends a file's left channel to output 1 and its right to output 2, so a mono file comes out of only one speaker. Describe the steps Curtis takes in the cue's Levels to make a mono file play out of both outputs at unity.Apply

    In the cue's Levels tab, the file shows a main fader plus the individual audio paths, one per output channel. By default the mono recording is assigned to only one output, so it plays from a single speaker. Curtis selects the file (or all three VOG files at once) and sends them to the second output channel at unity, meaning 0 dB with no level change, so the same mono signal feeds both outputs 1 and 2.

  3. 3.Curtis wants the keynote VO ("Please welcome to the stage Valerie Casey...") to roll straight into a music stinger. Explain how he uses Auto Follow together with the Time and Loops start-time control on both cues to build a tight transition, and what the yellow indicator next to a cue is telling him.Apply

    Auto Follow, toggled on a cue, makes the cue list advance to the next cue automatically as soon as the current one finishes, shown by a downward arrow on the cue. To make the join tight, Curtis opens Time and Loops on the VO and trims its start so it begins immediately, then sets the stinger's start time to land on the drop or chorus where the energy hits. The yellow indicator warns that the cursor is scrubbing a position different from the cue's saved start, so the cue reads as "mismatched" until he plays it from the set point, after which it shows as correct.

  4. 4.Curtis keeps cue numbers separate from cue names and color-codes cues by type (blue for pre-show, orange for in-show VOGs, yellow for stingers, red for the principal VO). Analyze why this redundant labeling helps an A1 who is also mixing the room, and what could go wrong with a list that relied on names alone.Analyze

    Color-coding lets the A1 read the whole list at a glance and know each cue by type without reading text, which matters when attention is split across the console, the stream, and the show caller's instructions. Separating the cue number from the name means the number stays a stable reference (001, Q102) that the caller and operator can share, while the name carries the full human-readable content. A names-only list forces the operator to read long strings under time pressure, which is slow and error-prone; color plus number gives instant, low-effort recognition of "the next blue pre-show cue" or "the yellow stinger."
