Takeaway

An 83-second snippet from Lively's 110 Questions series. Volker asks whether linear sound is really good sound. Lively spends the first half stacking up the practical wins a linear system buys, including same response from front-of-house to every seat, same translation to the broadcast truck and overflow room, same starting point on tour every night, less worry about technical problems mid-show, and more consistency for clients. Then he pivots: linear is not good sound, it is same sound. Garbage in still produces garbage out. The video pairs as a direct counterpoint to Devin Sheets's argument for a Fletcher-Munson-derived default EQ over a measurement-flat tune.

Before you watch

Prerequisites

  • Awareness that measurement-flat (linear) PA tuning is a common reference point
  • Familiarity with the idea that different rooms color a system differently

By the end you'll be able to

  • Paraphrase Lively's distinction between 'good sound' and 'same sound' as goals for system tuning
  • Identify what a linear system protects against and what it does not
