One-Click Bookmarklet Setup

Parse BandLab sample packs instantly while browsing, without downloading HTML files.

Setup Required

Enter the full path to your index.html file below. You can find this by opening index.html in your browser and copying the full address from the address bar.

Drag This Button to Your Bookmarks Bar

Parse BandLab Pack

Or right-click and select "Bookmark This Link" / "Add to Bookmarks"

0 Generate Your Bookmarklet

The page should automatically fill in the correct path. If not:

  1. Open index.html in your browser
  2. Copy the entire address from the address bar (should start with file:/// or https://)
  3. Paste it into the input field above
  4. Click "Generate My Bookmarklet"
1 Install the Bookmarklet

Drag the purple button that appears to your browser's bookmarks bar (usually below the address bar). If you don't see your bookmarks bar:

  • Chrome/Edge: Press Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac)
  • Firefox: Press Ctrl+B (Windows) or Cmd+B (Mac)
  • Safari: Press Cmd+Shift+B
2 Navigate to BandLab

Go to any BandLab sample pack page while logged in. For example:

https://www.bandlab.com/sounds/packs/[pack-id]

Important: Make sure the page is fully loaded and all samples are visible.

3 Click the Bookmarklet

Click the "Parse BandLab Pack" bookmark in your bookmarks bar. A new tab will open with the parser, automatically processing the page data.

The bookmarklet will extract:

  • Pack name and metadata
  • All sample information
  • BPM, key, duration, and other attributes
  • The pack URL automatically
4 Automatic Download

The JSON file will be automatically downloaded with the correct filename matching BandLab's .zip format. You can review the metadata in the parser if you need to make any edits and re-download.

Important Notes
  • Must be logged in: You need to be logged into BandLab for the page to load properly
  • Wait for full load: Ensure all samples have loaded before clicking the bookmarklet
  • Works locally: This tool processes everything in your browser - no data is sent to any server
  • Same domain: The bookmarklet works best when this HTML file is opened from the same location (local file system or hosted domain)

How It Works

The bookmarklet is a small piece of JavaScript that runs on the BandLab page when you click it. It captures the current page's HTML and URL, then sends that data to the parser tool in a new tab. Since you're already logged in to BandLab, the bookmarklet has access to the full page content.

Privacy: All processing happens locally in your browser. No data is sent to external servers.
