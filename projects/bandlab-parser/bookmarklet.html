One-Click Bookmarklet

Parse BandLab sample packs instantly while browsing.

Drag to Your Bookmarks Bar

Parse BandLab Pack

Or right-click and select "Bookmark This Link"

1 Install the Bookmarklet

Drag the button above to your browser's bookmarks bar. If you don't see it:

  • Chrome/Edge: Ctrl+Shift+B (Win) or Cmd+Shift+B (Mac)
  • Firefox: Ctrl+B (Win) or Cmd+B (Mac)
  • Safari: Cmd+Shift+B
2 Navigate to BandLab

Go to any BandLab sample pack page while logged in:

https://www.bandlab.com/sounds/packs/[pack-id]

Make sure the page is fully loaded and all samples are visible.

3 Click the Bookmarklet

Click "Parse BandLab Pack" in your bookmarks bar. A new tab will open with the parser, automatically extracting:

  • Pack name and metadata
  • All sample information
  • BPM, key, duration, and other attributes
4 Download JSON

The JSON file will automatically download with the correct filename. Review the metadata in the parser if you need to make edits.

Important Notes
  • Must be logged in to BandLab for the page to load properly
  • Wait for full load before clicking the bookmarklet
  • Privacy: All processing happens locally in your browser

How It Works

The bookmarklet captures the current page's HTML and sends it to the parser in a new tab. Since you're logged into BandLab, it has access to the full page content. No data is sent to external servers.
